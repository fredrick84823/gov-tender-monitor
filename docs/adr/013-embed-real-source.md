# 013. 展示網頁內嵌真實原始碼，不重寫瀏覽器版

**狀態**：已實作　**決策者**：我

## 背景

課堂展示網頁要能互動 —— 讓學員當場改規則、看命中與排除的變化。

兩種做法：為瀏覽器重寫一份過濾邏輯，或內嵌真實的原始碼。

另有一個環境限制：發布出去的網頁**無法對外連線**（CSP 只允許少數 CDN，
政府採購網不在名單內），所以無法即時查詢。

## 決策

build 腳本把 `src/dates.js`、`src/select.js`、`src/workbook.js` 逐字嵌入網頁，
只做最小轉換（去掉 `export` 與 import 敘述，`ExcelJS` 改用 CDN 的 global）。

資料改用預先擷取的 2026-08-17 真實資料（全天 1787 筆 + 62 筆細查），
過濾與產表在瀏覽器裡真的執行。

## 理由

重寫一份的話，兩邊會慢慢走偏，示範也失去意義。內嵌真實原始碼，才能說
「網頁上跑的就是那 89 條測試驗證過的同一份程式」。

exceljs 4.4.0 在 cdnjs 上，與專案依賴同版本，所以連 xlsx 產出都是真的。

## 後果

- 網頁能產出真正的 xlsx（透過 `downloads` 能力交給瀏覽者）。
- 兩條誠實聲明必須顯示在頁面上：資料是預先擷取的；只取得了預設規則下命中與
  排除的 62 筆細查，放寬規則後新出現的標案，預算與截止投標會顯示「未擷取」。
- 對課堂而言這比即時連線更好：不會 30 個學員同時打爆志工維運的 API。
