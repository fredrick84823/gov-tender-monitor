# 010. 預算未公開不補 0；細查失敗整份失敗

**狀態**：已實作　**決策者**：規格第六節要求，實作細節由我決定

## 背景

規格第六節「資料誠實原則（曾修正的重點）」：

> - **民國年 → 標「未公開」，絕不補 0**。
> - 抓不到就 fail-loud；API 429 退避重試。

規格註明這是「客戶看到才發現後補上」的條款 —— 也就是曾經出過事。

## 決策

**預算**：`預算金額是否公開` 開頭為「否」時，預算一律留 `null`，表格印「未公開」。
解析失敗也回 `null`，絕不回 `0`。

**失敗**：任何一筆細查失敗都讓整個 `runDailyReport` 拋出，不產出報表。

## 理由

一個 0 和一個「未公開」在 Excel 上看起來都像資料，但意義完全相反。客戶看到 0
會以為這案子沒預算，而實際上是機關沒公開。

寧可整份報表不出，也不出一份看起來完整、但少了預算與截止日的表 —— 後者會讓客戶
在不知情的情況下做決定。

## 實作上的坑

API 的實際回應形狀比規格想像的麻煩：

- `預算金額` 是字串 `"1,000,000元"`，不是數字。
- `預算金額是否公開` 是**多行字串** `"否\n預算金額涉及商業機密"`
  —— 不能用 `=== "否"` 比對，必須用開頭比對。
- `採購金額級距`（如「公告金額以上未達查核金額」）在預算未公開時仍存在，
  保留作為粗略參考。

這三點各有一條測試釘住。
