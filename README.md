# 公標網 — 政府標案每日監控

每天自動查詢政府電子採購網，篩出「媒體服務／廣告／行銷／公關」相關的當日新招標，
依規則過濾去重後，產出帶官網連結的 Excel，於 18:30 前 Email 給相關夥伴。

- 客戶：某媒體代理商的媒體中心（已去識別化）
- 需求規格：[`docs/requirements.md`](docs/requirements.md)

## 現況

規格已定案，實作尚未開始。

## 關於這個 repo

這是一份 AI 培訓課程的作業，模擬真實客戶需求。**客戶身分已去識別化**；
搜尋規則（關鍵字與排除清單）保留原樣，因為那是這個題目的核心。

資料來自政府電子採購網的公開資料，經由開放文化基金會維運的
[公開介面](https://pcc-api.openfun.app/) 取得。
