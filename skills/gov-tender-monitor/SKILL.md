# 公標網 — 政府標案每日監控

每天從政府電子採購網撈出「媒體服務／廣告／行銷／公關」相關的招標公告，
依規則過濾去重，產出帶官網連結的 Excel。

**這個 skill 只是操作這條管線的前門。** 管線本身是純 Node，不含 LLM，
行為由 89 條測試固定。你的工作是叫它、讀它的輸出、回答關於結果的問題，
**不要自己重新實作過濾邏輯或重算結果**。

## 第一次使用：先確認裝好了

執行 `bash ${CLAUDE_SKILL_DIR}/scripts/bootstrap.sh`。

它會找出（或 clone）專案、裝相依套件、跑測試、並用離線黃金檔驗證這台機器
的產出與基準一致。最後會印出專案路徑，後續指令都在那個目錄下執行。

已經裝好時它會直接回報路徑，不會重做，可以放心重複執行。

## 產出報表

```bash
npm run report -- --date 20260817     # 指定日期（西元 YYYYMMDD）
npm run report                        # 今天
```

輸出在 `out/公標案查詢-<日期>.xlsx`。指令會印出摘要：取得幾筆公告、命中幾筆、
排除幾筆、其中幾筆是更正公告、幾筆預算未公開。**把這份摘要如實轉述給使用者**，
特別是「預算未公開」的筆數 —— 那些欄位是刻意留空的，不是抓取失敗。

一次查詢約需 1–2 分鐘：當日全部公告一次取得，命中的才逐案細查，
且刻意限速在每秒一次以內（資料源對匿名呼叫有速率限制）。

## 回答「這個標案為什麼沒出現？」

這是最常被問的問題，依序檢查，不要猜：

1. **公告類型** — 只收 10 種招標類公告。決標、無法決標、定期彙送、財物出租
   一律不收。清單在 `config/rules.json` 的 `announcementTypes`。
2. **採購性質** — 只收勞務類。工程類、財物類即使標題有「媒體」也不收。
3. **兩條命中路徑** — 標的分類命中 871/875/879/96（路 A），或標案名稱含
   關鍵字（路 B）。兩條都沒中就不會出現。
4. **排除清單** — 38 條排除詞對標案名稱做字串比對，命中即擋。
   **被擋下的案子會列在 Excel 最後的「已排除」分區**，標明是被哪一條擋下的。
   先去那裡找，通常答案就在那。

排除清單是純字串比對，會誤殺。例如「台中市OO活動中心啟用晚會宣傳影片製作」
會被「活動中心」這條擋掉，但那其實是客戶要的案子。遇到這種情形，
是排除詞訂得太寬，不是程式有錯 —— 回報給使用者，讓他們決定要不要改規則。

## 調整規則

規則全部在 `config/rules.json`，改完不需要改程式：

- `keywordGroups` — 四組關鍵字（媒體廣宣／數位社群／活動節慶／AI）
- `titleExclusions` — 排除詞清單
- `announcementTypes` — 收錄的公告類型
- `categories` — 標的分類大類

**改動規則後，`npm run verify` 一定會失敗** —— 它比對的是舊基準。
確認新結果正確後執行 `npm run verify:update` 更新黃金檔，並告知使用者
基準已變更。

## 這個 skill 不做的事

- **不排程。** 它只在你被叫起來時才動。要每天固定時間跑，需要作業系統層級的
  排程器直接呼叫 `npm run report`，不需要經過 Claude Code。
- **不寄信。** 目前只產出檔案。
